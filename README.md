# Accessible Enterprise Dashboard

## Overview

This project is an accessible enterprise dashboard built using HTML5, CSS3, and JavaScript.

The dashboard follows semantic HTML5 structure and WCAG 2.1 accessibility principles to provide a clear, keyboard-friendly, and user-friendly interface.

## Features

- Semantic HTML5 structure
- Accessible navigation header
- Sidebar navigation
- Dashboard overview cards
- Recent activity data table
- Accessible contact form
- Form validation
- Accessible modal dialog
- Skip-to-content link
- Keyboard accessibility
- Responsive design
- Reports page
- Settings page

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Accessibility

The project includes:

- Semantic HTML elements
- Proper heading hierarchy
- Labels for form controls
- Fieldset and legend
- ARIA labels
- ARIA live status
- Keyboard focus indicators
- Required field validation
- Accessible modal dialog
- Skip navigation link
